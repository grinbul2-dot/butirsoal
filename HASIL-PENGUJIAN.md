# Hasil pengujian v2.2.0

Pengujian otomatis Node mencakup alur satu arah, kegagalan pada halaman 2, parameter terkunci, pemblokiran analisis ulang dari hasil, revisi ke siklus baru, reset isian/gambar/cache, serta penghapusan pekerjaan yang masih berjalan tanpa pemunculan data kembali.

Termasuk validasi output, escaping HTML, tujuh kategori dan kunci, pembacaan gambar, polling setelah koneksi putus, retry/fallback dan batas waktu. Endpoint aplikasi dan kebutuhan key diperiksa menggunakan Gemini.

Respons provider disimulasikan. Belum ada uji API berbayar, verifikasi visual browser, atau deploy produksi pada sesi ini.
